# Code of Conduct

Core Terminal is a public project. Contributions and support should be
welcoming, specific, and directed at the work.

Expected behavior includes:

- using a respectful, professional tone;
- explaining disagreements with evidence and without personal attacks; and
- respecting other people's time, privacy, and boundaries.

Unacceptable behavior includes harassment, discrimination, threats,
publication of private information, sexualized attention, and deliberately
disruptive conduct. Do not post credentials, private profile files, or other
sensitive data in issues, pull requests, or logs.

Maintainers may edit, close, or remove contributions and may restrict project
access when necessary to protect participants or the project. The same rules
apply in issues, pull requests, reviews, and other project spaces.

Report a conduct concern privately to the maintainers through the contact
options in the repository. Do not use a public issue for a sensitive report.
